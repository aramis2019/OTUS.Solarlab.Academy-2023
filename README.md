# Solarlab.Academy-2023
Учебный проект в рамках курса Соларлаб Академия Backend 2023

## Секреты

Секреты (ключ подписи JWT, пароль БД) в репозитории не хранятся.

- **docker-compose** берёт их из файла `.env` рядом с `docker-compose.yml` (он в `.gitignore`):

  ```
  cp .env.example .env
  # задать JWT_KEY (минимум 32 символа), например: openssl rand -base64 48
  ```

- **Локальный запуск API** (`dotnet run`, окружение Development) — ключ задаётся через user-secrets:

  ```
  cd src/Board/Host/Board.Host.Api
  dotnet user-secrets set "Jwt:Key" "<случайная строка не короче 32 символов>"
  ```

  Строка подключения к локальной БД лежит в `appsettings.Development.json`.

- В остальных окружениях — через переменные окружения `Jwt__Key` и `ConnectionStrings__PostgresBoardDb`.

- **AutoMapper** (версии 15+) распространяется по коммерческой лицензии: ключ задаётся в `AutoMapper:LicenseKey`
  (user-secrets, переменная `AutoMapper__LicenseKey` или `AUTOMAPPER_LICENSE_KEY` в `.env`).
  Без ключа приложение работает, но AutoMapper пишет предупреждение в лог.

Без `Jwt:Key` API не запустится.

## Администраторы

Логины администраторов перечисляются в `Administration:AdminLogins` (например, переменная окружения
`Administration__AdminLogins__0=admin`). Администратор управляет категориями (создание, изменение, удаление —
обычным пользователям недоступно) и может изменять и удалять любые объявления и файлы, в том числе созданные
до появления авторства. Роль попадает в JWT при входе, поэтому после изменения списка нужно войти заново.

Разрешённые для CORS источники задаются в `Cors:AllowedOrigins` (по умолчанию список пуст). Swagger доступен только в окружении Development.

## docker-compose 

Нужен Docker Compose v2 (`docker compose`) или `docker-compose` версии 1.29 и новее:
мигратор ждёт, пока PostgreSQL станет доступен, а API — пока мигратор успешно завершится.

- Для запуска контейнеров выполняем:

	`docker compose up -d`
	
  Запускаются сервисы:
  - персистентный сервис для работы с БД (PostgreSQL), доступен только с локальной машины:
    - 127.0.0.1:5432
  - сервис миграций БД: применяет миграции, хеширует пароли, оставшиеся в открытом виде от старых версий, и завершается;
  - сервис WebAPI (прокидываем 8080-й порт из контейнера на 5000-й порт локальной машины):
    - 5000:8080
  - adminer, доступен только с локальной машины:
    - 127.0.0.1:8080

- Проверить состояние сервисов: 
  
  `docker-compose ps` 

- Отключение: 
  
  `docker-compose down` 
  
  (порты свободны, сохраняется **persisted volume** для БД).
